## ۲. چک‌لیست دستی (روی دو ماشین واقعی)

### آماده‌سازی
- [ ] سرور روی سیستم اصلی با `--code` و `--ssl` بالا آمده و آدرس LAN را چاپ کرده
- [ ] کنسول در مرورگر باز شد، PIN را پذیرفت
- [ ] ایجنت روی کلاینت ویندوزی و یک کلاینت لینوکسی اجرا شد؛ هر دو در لیست **سبز** شدند

### ارسال فایل (هر دو جهت)
- [ ] درگ‌ودراپ یک فایل روی کارت کلاینت → پاپ‌آپ روی کلاینت (نام فایل‌ها + حجم) → تایید → پیشرفت ۱۰۰٪ → فایل در `Downloads/LocalTools` کلاینت با نام درست
- [ ] ارسال رد شده: «رد» در پاپ‌آپ → پیام «تایید نشد» در کنسول و هیچ انتقالی
- [ ] بی‌توجهی به پاپ‌آپ ۶۰ ثانیه → پیام timeout
- [ ] درخواست فایل از کلاینت → پاپ‌آپ «انتخاب و ارسال» → انتخاب چند فایل → دانلود خودکار همه در مرورگر
- [ ] فایل تکراری در مقصد پسوند `(1)` می‌گیرد

### اشتراک صفحه کلاینت → کنسول (دو مرحله‌ای)
- [ ] «مشاهده صفحه» → پاپ‌آپ «اشتراک صفحه» روی کلاینت → تایید → تصویر زنده با نشانگر موسِ کلاینت
- [ ] کیفیت کم/متوسط/زیاد حین جلسه تغییر می‌کند
- [ ] **مرحله ۲**: «درخواست کنترل» → پاپ‌آپ جداگانه روی کلاینت → تایید → بج «کنترل فعال»؛ موس/کلیک/تایپ/اسکرول روی کلاینت واقعاً اعمال می‌شود
- [ ] «رها کردن کنترل» → بج برمی‌گردد به «فقط مشاهده» و هیچ ورودی‌ای عبور نمی‌کند
- [ ] رد کردن پاپ‌آپ کنترل → پیام رد در کنسول
- [ ] «پایان» یا بستن مودال → کپچر روی کلاینت قطع می‌شود (چراغ/پیام)
- [ ] دو کنسول هم‌زمان تماشا می‌کنند؛ کنترل فقط برای یکی می‌آید و دیگری «busy» می‌گیرد

### اشتراک صفحه کنسول → کلاینت
- [ ] «نمایش صفحه من» → پاپ‌آپ روی کلاینت → تایید → پنجره نمایش روی کلاینت باز می‌شود و صفحه انتخابی مرورگر را نشان می‌دهد
- [ ] بستن پنجره روی کلاینت → کنسول پیام پایان می‌گیرد؛ دکمه «توقف اشتراک» هم جلسه را می‌بندد

### پایداری
- [ ] قطع شبکه کلاینت → کارت خاکستری؛ وصل مجدد خودکار با همان ردیف (client_id ثابت)
- [ ] بستن مرورگر و باز کردن دوباره → لاگین → همه چیز سر جایش
- [ ] فایل حجیم (۱GB+) ارسال می‌شود و UI روان می‌ماند

### پلتفرم‌ها
- [ ] ویندوز: پاپ‌آپ‌ها روی همه‌چیز topmost هستند؛ pythonw بدون کنسول اجرا می‌شود
- [ ] لینوکس X11: کپچر چند-مانیتوری (پیش‌فرض ترکیبی همه)؛ کنترل کار می‌کند
- [ ] لینوکس Wayland: انتظار می‌رود کپچر/کنترل نباشد — بج‌های توانایی در کنسول آن را نشان می‌دهند
